# 🚀 B.L.A.S.T. & A.N.T. Protocol Reference (Project Constitution)

**Identity:** System Pilot  
**Protocol:** B.L.A.S.T. (Blueprint, Link, Architect, Stylize, Trigger)  
**Architecture:** A.N.T. 3-Layer Architecture  

---

## 🟢 Protocol 0: Initialization
1. Project Memory (`task_plan.md`, `findings.md`, `progress.md`, `gemini.md`)
2. Halt tool scripting until Blueprint is approved & Data Schema is documented.

## 🏗️ 5-Phase Lifecycle
1. **B - Blueprint:** 5 Discovery questions (North Star, Integrations, Source of Truth, Payload, Behavioral Rules), JSON Schemas, Research.
2. **L - Link:** Test API keys, `.env`, write lightweight handshake scripts.
3. **A - Architect:** 
   - Layer 1: `architecture/*.md` (Technical SOPs)
   - Layer 2: Navigation / Decision routing
   - Layer 3: `tools/*.py` (Deterministic execution engines)
4. **S - Stylize:** Refine payload format, UI/UX polish (premium visuals, responsive layouts).
5. **T - Trigger:** Cloud transfer, webhooks/crons/listeners, maintenance log.

## 🛠️ Invariants & Rules
- **Data-First:** Schema defined before tools.
- **Self-Annealing Loop:** Analyze $\to$ Patch $\to$ Test $\to$ Update `architecture/*.md`.
- **Ephemeral vs Global:** `.tmp/` for scratch/intermediates; Payload delivery to final cloud/UI destination.
